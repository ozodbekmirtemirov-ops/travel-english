# ✈️ TRAVEL ENGLISH

**Learn English. Travel confidently.**

Интерактивное приложение для изучения английского языка для путешествий.

🌐 **Открыть:** https://ozodbekmirtemirov-ops.github.io/travel-english/

- 600 учебных единиц: 200 слов, 200 словосочетаний, 200 предложений
- 30 уроков: Learn → Recognize → Remember → тест (минимум 70%)
- Повторение ошибок, прогресс, серия дней, озвучка
- Режим путешествия: «Слово часа» и виджет для экрана блокировки iPhone (через Scriptable — файл `TravelEnglish-widget.js`)
- Работает офлайн, устанавливается на телефон: Safari → «Поделиться» → «На экран Домой»
